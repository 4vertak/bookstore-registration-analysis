# Алгоритм обработки запроса регистрации на бэкенде

При получении `POST /api/v1/auth/register` сервис выполняет следующие шаги:

1. **Проверка Content-Type**  
   Если заголовок `Content-Type` не `application/json`, вернуть `415 Unsupported Media Type` с телом:
```json
{
   "success": false,
   "errorCode": "UNSUPPORTED_MEDIA_TYPE",
   "message": "Content-Type must be application/json"
}
```

2. **Десериализация и базовая валидация полей**  
   Проверить наличие всех обязательных полей: `firstName`, `lastName`, `username`, `password`, `captchaToken`.  
   Если отсутствует хотя бы одно – вернуть 400 Bad Request с телом, содержащим errorCode: VALIDATION_ERROR и объект errors с перечнем отсутствующих полей.

Пример:

```json
{
  "success": false,
  "errorCode": "VALIDATION_ERROR",
  "errors": {
    "firstName": ["Required"],
    "lastName": ["Required"],
    "username": ["Required"]
  }
}
```

3. **Проверка пароля**  
   Проверить, что пароль соответствует требованиям:
   - минимум 8 символов
   - хотя бы одна цифра
   - хотя бы один не алфавитно-цифровой символ (спецсимвол)
   - хотя бы одна заглавная буква (A-Z)
   - хотя бы одна строчная буква (a-z)
   Если не соответствует – вернуть `400 Bad Request` с `errorCode: INVALID_PASSWORD`.

4. **Проверка captcha**  
   Отправить `captchaToken` на верификацию в Google reCAPTCHA.  
   Если ответ от Google отрицательный или токен невалидный – вернуть `400 Bad Request` с `errorCode: CAPTCHA_REQUIRED`.

5. **Проверка уникальности username**  
   Выполнить запрос к БД: `SELECT COUNT(*) FROM users WHERE username = ?`.  
   Если количество > 0, вернуть `409 Conflict` с `errorCode: USER_ALREADY_EXISTS`.

6. **Хеширование пароля**  
   Сгенерировать соль и хеш пароля (например, bcrypt).

7. **Сохранение пользователя**  
   Выполнить `INSERT INTO users (firstName, lastName, username, password_hash) VALUES (?, ?, ?, ?)`.

8. **Обработка непредвиденных ошибок**  
   Если на любом этапе произошла ошибка (например, база данных недоступна), вернуть `500 Internal Server Error` с `errorCode: INTERNAL_ERROR`.

9. **Успешный ответ**  
   Вернуть `201 Created` и тело `{ "success": true, "message": "User Register Successfully" }`.
